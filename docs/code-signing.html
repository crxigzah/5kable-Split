Code signing policy

How Wideside's Windows releases are built, checked and signed.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What gets signed

Only binaries built from the source code in the crxigzah/wideside repository are signed: Wideside.exe and the installer Wideside-Setup-<version>.exe. Every release is built automatically by GitHub Actions from the main branch, so each signed file can be traced back to the exact commit it was built from.

Team roles and their members

  • Committers and reviewers: @crxigzah
  • Approvers: @crxigzah

Every signing request is approved manually by an approver before a release is published.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Wideside has no telemetry, accounts or analytics. Its only network action is opening this website in your browser when you click the Website link in its About window. Settings are stored locally in %AppData%\Wideside.

Features

Two monitors' worth of space. One screen.

Big monitors are great until you're dragging windows around by hand. Wideside gives every window a place to land.

Drag to snap

Hold Shift while dragging and the zones appear. The one under your mouse lights up; let go and the window fills it exactly.

Keyboard shortcuts

Win + Alt + arrows moves windows between zones. Win + Alt + a number sends one straight to a zone.

Layouts that fit

Halves, thirds, a focus column, stacked or quarters. Switch with one shortcut, or define your own.

Pixel-perfect edges

Allows for Windows 11's invisible window borders and display scaling, so windows line up with even gaps.

Any monitor

Built for ultrawides like the MSI MAG C42CQR E2, but it reads your resolution and taskbar, and works across multiple screens.

Tiny and quiet

A 1.5 MB tray app with no account, no telemetry and no admin rights needed to install.

Layouts

Split it your way

Seven layouts built in, each with an adjustable gap. Pick one from the tray, or press Win + Alt + L to cycle through them.

FAQ

Good to know

Does Windows see it as two monitors?

No, and neither does Dell Easy Arrange. Wideside snaps windows into zones on one display, so maximised windows, full-screen games and full-screen video still use the whole panel. Use Shift + drag or Win + Alt + arrows instead of maximising.

Why does Windows say "Windows protected your PC"?

SmartScreen shows that for new apps that aren't code-signed yet. Click More info, then Run anyway. The full source code is on GitHub, and every installer is built there automatically from that code.

Can I make my own layouts?

Yes. Open Settings from the tray icon, click "Edit custom layouts", add a line describing your zones, then choose Reload from the tray menu. There are examples in the file to copy.

Does it work with multiple monitors?

Yes. Zones are worked out for whichever monitor the window (or your mouse) is on, using that screen's own resolution, scaling and taskbar.

Some windows won't move. Why?

Apps running as administrator, such as Task Manager, can't be moved by a normal app. Run Wideside as administrator if you need those too. A few apps also have a minimum width and won't shrink fully into a narrow zone.

How do I uninstall it?

Settings → Apps → Installed apps → Wideside → Uninstall. Your layout settings stay in %AppData%\Wideside in case you reinstall; delete that folder to remove them too.

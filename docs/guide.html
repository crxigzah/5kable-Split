Using Wideside

Wideside splits a big monitor into zones. Drag a window and drop it on a zone, and it fills that zone exactly, like Dell Easy Arrange. This guide covers everything it can do.

Install

  1. Download Wideside-Setup.exe and run it. It installs just for you, so it doesn't need admin rights.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. Windows shows this for new apps that aren't code-signed.
  3. Leave Start Wideside when Windows starts ticked if you want it running all the time.
  4. Wideside runs in the system tray, next to the clock. Click the orange icon for Settings, or right-click it for the menu. If you can't see it, click the ^ arrow to show hidden icons and drag it onto the taskbar.

Portable version: the portable .zip contains Wideside.exe and this guide. Unzip it anywhere and run the exe. Nothing gets installed.

Snapping windows

Drag any window by its title bar. Once it starts moving, every zone appears as an orange outline with its number in the corner. The zone under your mouse gets a thick outline and a light orange tint. Let go, and the window fills that zone exactly.

Mouse over zone 2: drop to fill it
Three columns: drop in the middle
  • Maximised windows work too. Drag them off the top and drop them on a zone.
  • Just clicking a title bar doesn't show the zones. They only appear once the window has actually moved.
  • Windows' own Snap (edge snapping and the layout bar at the top of the screen) is paused while Wideside runs, so the two don't fight. It comes back when you close or pause Wideside.

Moving windows freely

Hold Ctrl while dragging to move a window anywhere without snapping. The zones disappear while Ctrl is held and the window stays exactly where you drop it. You can press Ctrl partway through a drag.

To turn snapping off for a while, press Win Alt P or choose Pause snapping in the tray menu. Do the same again to turn it back on.

Spanning zones

Drop a window on the line between two zones and it fills both. The highlight shows the combined area before you let go. Near a corner where four zones meet, it takes all four.

Three columns: drop on the line between 2 and 3

Browser tabs on each side

To have a browser on each side with its own tab bar, use separate browser windows. Drag a tab down off the tab bar, keep dragging, and drop it on a zone. It becomes its own window filling that zone. This works in Chrome, Edge, Opera, Brave and other Chromium browsers.

Opera users: Opera's own split screen catches tab drags with its "Drop tab here to split screen" cards. Press Alt P in Opera, search split screen, and turn off Enable a split screen by drag and drop.

The zone hotkeys and Arrange all work on the monitor the active window is on.

Layouts

Pick a layout in Settings, from Layout in the tray menu, or cycle through them with Win Alt L. Zones are numbered left to right, then top to bottom.

LayoutZones
Two halves (50/50)Left half, right half
Wide left (60/40)A wider left zone and a narrower right one
Wide right (40/60)The same, mirrored
Three columnsThree equal columns
Focus centre (25/50/25)A big middle column with narrow sides
Left half + right stackedLeft half, with the right half split top and bottom
Four quartersA 2 × 2 grid

Gap between windows in Settings adds an even gap around and between windows (0 to 24 px). At 0 they fill the screen edge to edge.

Custom layouts

In Settings, click Edit custom layouts…. That opens the settings file in Notepad. Add lines under [CustomLayouts], save, then choose Reload from the tray menu. Your layouts appear after the built-in ones.

Each line is a name, then the zones separated by |. Each zone is four numbers from 0 to 1, as fractions of the screen: left, top, width, height.

[CustomLayouts]
; Big window on the left, two stacked on the right
Coding=0,0,0.65,1 | 0.65,0,0.35,0.5 | 0.65,0.5,0.35,0.5

; Two halves with a narrow strip on the far right for chat
Halves + chat=0,0,0.4,1 | 0.4,0,0.4,1 | 0.8,0,0.2,1

; Top two-thirds across the screen, two zones underneath
Wide top=0,0,1,0.66 | 0,0.66,0.5,0.34 | 0.5,0.66,0.5,0.34

Check your numbers if a layout doesn't show up. Each zone needs exactly four values between 0 and 1, and any mistake on a line makes Wideside skip that line.

Settings

Click the tray icon to open Settings. Changes apply straight away.

SettingWhat it does
LayoutWhich set of zones to use, with a live preview shaped like your monitor.
Gap between windowsSpace around and between snapped windows. 0 px fills the screen edge to edge.
Only show zones while holding ShiftOff by default. When on, zones only appear if you hold Shift while dragging, and normal drags never snap.
Turn off Windows Snap while Wideside runsOn by default. Pauses Windows' built-in snapping so it doesn't compete with the zones. It's restored when Wideside closes or is paused.
Reopen apps in the zone they were last snapped toOn by default. See Remembered apps.
Check for updates automaticallyOn by default. See Updates.
Start Wideside with WindowsRuns Wideside when you sign in.

Settings are saved in %AppData%\Wideside\settings.ini, so they're kept when you update.

Remembered apps

Whenever you snap a window, Wideside remembers which zone that app was in. The next time you open the app, its window goes straight back there. Snap Opera to the right once, and it opens on the right from then on.

To avoid surprises, this only happens when it's the app's only window and you're using the same layout as when it was saved. Extra windows, dialogs and tabs you pull off aren't moved. Snap the app somewhere else to change its remembered zone.

Updates

Wideside checks GitHub for a new version a few seconds after it starts, then every 6 hours. When one is out, you get a notification and the tray menu shows Update to version X. Click it to download and run the new installer. It upgrades in place and keeps your settings.

To check yourself, choose Check for updates in the tray menu. The update check is the only time Wideside goes online, and you can turn it off in Settings.

Troubleshooting

Some windows won't move or snap

Apps running as administrator, such as Task Manager, can't be moved by a normal app. Right-click Wideside in the Start menu and choose Run as administrator if you need those too.

A window doesn't fill its zone

Some apps have a minimum width and won't shrink below it. Use a wider zone, or a layout like Wide left (60/40).

There's a thin line between windows at 0 px gap

That's the 1px border Windows 11 draws around every window, not a gap.

Windows Snap stays off after Wideside closes

Wideside turns Windows Snap back on when it exits normally. If it was force-closed, signing out and back in restores it. You can also check Settings → System → Multitasking → Snap windows.

I changed monitors or resolution

Zones are worked out again automatically. If anything looks off, choose Reload from the tray menu.

Something else

Report a problem on GitHub and say what you were doing and what happened.

Uninstall

Go to Settings → Apps → Installed apps → Wideside → Uninstall. Your settings stay in %AppData%\Wideside in case you reinstall. Delete that folder to remove them too. For the portable version, delete the folder you unzipped.
